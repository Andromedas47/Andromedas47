## 🚀 Featured Projects

### [Bot Summary](https://github.com/Andromedas47/Bot-summary)

A production LINE-based operations system for inventory tracking, slip processing, daily summaries and reconciliation.

The system supports real operational workflows across multiple locations and is designed to prevent incomplete or duplicated records.

**Key engineering considerations**

- Fail-closed data validation
- Duplicate and idempotency protection
- Session-based operation flows
- Daily inventory reconciliation
- Scheduled processing
- LINE Messaging API integration
- Production incident investigation

**Tech Stack**

`Next.js` `TypeScript` `Supabase` `PostgreSQL` `LINE Messaging API` `Vercel`
